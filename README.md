## Description

The notebook provides an overview of the initial steps and offers recommendations for selecting a point of interest (PoI) when user sequences are unavailable. It uses a 2-layer graph neural network (GNN) to vectorize vertex characteristics. However, this initial concept can be improved upon. The notebook also suggests future directions and provides lectures. 

Notice: this notebook and dataset are provided for educational purposes only.
